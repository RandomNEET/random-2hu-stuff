# 数据更新维护指南

适用于 `update/`，同时遵守 [根目录指南](../AGENTS.md)。本目录是人工表格与数据库之间的维护工具集，并非后端 API 的写入接口。

## 入口与业务依据

- [readme.md](readme.md) 定义收录、在线表格列、原视频与转载视频对应关系和备注规则。处理数据前先读相关规则；不能用查重或归一化算法替代人工收录判断。
- [scripts/AGENTS.md](scripts/AGENTS.md) 管理导入、数据库维护、元数据、公告和源码上传工具。
- [autofetch/AGENTS.md](autofetch/AGENTS.md) 管理 RSS → 本地 CSV → 信息补全 → 腾讯文档的流水线。
- 自动抓取结果仍是待检查数据，不能直接视为网站已经收录；数据库导入与在线表格上传是不同步骤。

## 跨工具约束

- 保持原作者、原视频与转载视频的对应关系。相同链接可能表示拆分、合并或合集分话，不得未经判断就删除重复记录或丢弃分 P 参数。
- 翻译状态、表内外备注和 CSV 列顺序遵循业务说明；未知值和空值不自动替换为某个合法状态。
- 修改字段、输出文件名、日期格式或链接规范化后，检查下游导入、处理、上传、前端分组及测试。不要只修改单个阶段。
- 先确认每个脚本的路径解析及副作用：根 `.env`、autofetch 的 `config/.env`、`PROJECT_ROOT` 与工作目录并不是统一配置机制。
- 数据库、cookies、抓取状态、CSV/XLSX 输出与备份仅供本地使用；保留根 `.gitignore` 已有业务文件例外，不提交凭据或真实测试数据。
- 验证使用临时路径、数据库和模拟网络；不要通过运行真实流水线检查代码。当前自动测试覆盖范围以 `test/update/` 为准，新增工具行为需选择或补充对应测试。

从仓库根目录执行 `npm run test:python`。该命令不代表已覆盖所有维护脚本；修改上传部署工具另检查 `npm run test:deploy`，修改公告结构另检查前端渲染及构建。
